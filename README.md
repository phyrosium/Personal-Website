# Modern Responsive Personal Portfolio

A sleek, high-performance personal portfolio website built with semantic HTML5, modern CSS3 (with CSS Custom Properties and responsive flex/grid layouts), and vanilla JavaScript.

## Features

- **Dark-Themed UI**: Modern glassmorphic cards, glowing gradients, and clean typography.
- **Responsive Navigation**: Sticky frosted-glass navbar with active section scroll-spy, and mobile drawer menu.
- **Hero / Header**: Headline title, bio summary, availability badge, and social quick links (GitHub, LinkedIn, Email).
- **Interactive About Section**:
  - Key skills showcase with interactive category filter pills (Frontend, Backend, DevOps & Cloud) and badge tap feedback.
  - Experience and education timeline with glowing markers.
- **Featured Projects**: 3 project cards with custom CSS UI mockups, tech badges, and "Live Demo" and "View Code" action buttons.
- **Interactive Contact Form**: Client-side validation, console logging of submission payloads, loading spinner state, and toast notifications.
- **Full Responsiveness**: Mobile, tablet, and desktop viewports.

## Quick Start

Open `index.html` in any modern web browser or host with GitHub Pages.

```bash
# Optional: serve with python or npx
python -m http.server 8080
# or
npx serve .
```
